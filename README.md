# Richmond Technology Solutions website

A responsive single-page marketing site for RTS, including anonymised LCOS product imagery derived from the supplied prototype.

## Preview locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Before publishing
1. Confirm or replace the contact email in `index.html`.
2. Connect the folder to Vercel, Netlify or another static host.
3. Replace the Google Fonts links with self-hosted or system fonts if required by your privacy policy.

All product screenshots use the LCOS name and omit the prospective customer identity.
